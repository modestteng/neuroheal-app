## 五、软件用途（直接复制下面整段，约 180 字）

```
本软件是一款面向高校学生心理健康辅助场景的脑电情绪监测与 AI 反馈干预闭环演示系统。
系统通过便携式 EEG 脑电采集设备持续获取用户脑电信号，识别 Valence 情绪效价等级，
由 AI 反馈模块生成温和的安抚语言与下一步干预建议，并支持用户进入呼吸训练、数字处方、
意念赛车调节游戏或 AI 心理陪伴等模块；干预完成后系统继续监测脑电信号、再次进行
效价判断，形成「监测—判断—反馈—干预—再监测」的可持续闭环。本软件为辅助干预性质，
不替代专业医疗诊断与治疗。
```

## 六、技术特点（直接复制下面整段，约 380 字）

```
1. 实时闭环主线：系统以 ValenceLoopProvider 全局状态钩子驱动「EEG 采集 → Valence
   识别 → AI 反馈 → 用户干预 → 再监测」的循环主线，每 9 秒推进一次效价快照，
   保证用户感知与状态变化同步。

2. 上下文感知的 AI 反馈：前端在每次调用 AI 反馈接口时，自动在消息体最前面插入隐藏
   的系统提示，携带当前 Valence 等级、score、置信度、信号质量与 EEG 摘要，使 AI
   能基于实时状态调整安抚语气与建议方向，而非给出固定回复。

3. 前后端分离的轻量架构：前端为 React 19 + TypeScript + Vite 8 构建的渐进式 Web
   应用（PWA），后端为 Node.js 原生 HTTP 服务，仅承载 AI 接口转发与密钥管理，
   不持久化任何业务数据，最大化用户隐私保护。

4. 简洁的 3 主 Tab + 6 子页结构：监测 / 干预 / 记录三主线突出主要功能；6 个子页
   面（设备校准、数字处方、呼吸训练、AI 陪伴、成长档案、意念赛车）作为干预手段
   支撑主线，整体信息层级清晰、视觉舒心。

5. 内容合规：所有 AI 反馈与界面文案均明确标注辅助性质，不冒充医生、不做医学诊断；
   危机场景下引导用户联系学校心理中心或当地紧急支持渠道。
```
