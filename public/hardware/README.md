# Hardware Assets

Place real hardware images, signal screenshots, thumbnails, and demo videos here.

Recommended paths:

- `/hardware/device-main.jpg`
- `/hardware/wearing-scene.jpg`
- `/hardware/eeg-signal-proof.jpg`
- `/hardware/hardware-demo.mp4`

After assets are added, update `src/data/hardware.ts` with the corresponding `src`, `thumbnail`, and `value` fields.
